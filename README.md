# NULLTRACE 4093

Frontend deployment package for the NULLTRACE 4093 ARG vertical prototype.

The source is stored as split base64 payload files under `payload/` because this repository was populated through the connected GitHub app from a local workspace without shell Git credentials. The GitHub Pages workflow restores the payload, installs dependencies, builds with Vite, and deploys `dist`.
