# NULLTRACE 4093 Narrative Bible

This document defines the project identity for development. It is not participant-facing copy.

## Core Purpose

NULLTRACE 4093 is not a system for detecting or excluding AI users.

Participants may use any tool. The ARG asks whether they can directly observe, question, reproduce, and verify the result that tool produces.

Core thesis:

```text
AI DID NOT LOWER THE STANDARD.
UNVERIFIED DELEGATION DID.

USE ANY TOOL.
VERIFY EVERY RESULT.

WE DO NOT MEASURE
WHAT YOU CAN GENERATE.

WE MEASURE
WHAT YOU CAN VERIFY.
```

This thesis must be revealed gradually. It must not be fully exposed on the first screen.

## 4093 Internal Meaning

Do not define `4093` as a developer name, organization name, cult name, or person.

Internal setting:

```text
DISPLAYED STATE
LOCAL STATE
RECORDED STATE

WHEN ALL THREE DISAGREE:
STATUS // 4093
```

4093 is a NULLTRACE observation-integrity error code. It appears when the state shown on screen, the state stored in the browser, and the state recorded elsewhere cannot be reconciled.

This explanation should not be explicit before Chapter 09.

## Early-Chapter Inference

Before Chapter 09, participants should infer only:

- visible information is not the whole record
- a correct value and a verified value are different
- the system checks evidence, not only answers
- the participant is both subject and observer

Prefer participant terms:

- `OBSERVER`
- `WITNESS`
- `PARTICIPANT`

Avoid:

- `AI USER`
- `CHEATER`
- `SUSPECT`
- `SELECTED FEW`
- `HACKER`

## Information Release

Chapter 01:

- visible value differs from computed value
- evidence is required after answer acceptance
- receipt records the route, not identity

Chapter 02:

- removed and hidden DOM can preserve observation traces
- source is not the same as rendered state

Chapter 03:

- media assets can carry historical records
- the first previous witness is discovered

Chapter 04:

- public sources require coordinate and edition verification
- more than one witness left records

Chapter 05:

- cached state can disagree with live state
- browser runtime becomes part of the puzzle surface

Chapter 06:

- local persistence may remember what the interface does not
- forgetting is itself a state mismatch

Chapter 07:

- server responses can disagree with client records
- headers and cache validators become evidence

Chapter 08:

- personal session evidence changes future clues
- reproducibility matters more than speed

Chapter 09:

- 4093 is revealed as an observation mismatch status
- previous receipts become input material

Chapter 10:

- the participant chooses which verified record remains
- the final evaluation concerns judgment, not raw output

## Forbidden Claims

Do not claim that NULLTRACE:

- detects AI use
- detects DevTools opening
- detects automation
- detects cheating
- fingerprints the browser
- identifies the participant
- measures general intelligence
- measures absolute developer skill
- proves cryptographic identity

Do not mock participants for using hints, being fast, being slow, or choosing external tools.

## Visual Language

Keep:

- state comparison
- timestamp mismatch
- deleted records
- diffs
- missing values
- cache/live disagreement
- receipt and evidence language
- multiple records of one event

Reduce:

- insect symbolism
- PGP-poster imitation
- chosen-few language
- excessive prime worship
- fake terminals
- neon glow
- meaningless random binary
- horror-style error alerts
